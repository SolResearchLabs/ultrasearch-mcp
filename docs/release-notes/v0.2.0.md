# UltraSearch MCP v0.2.0

Feature release for Claude Desktop MCPB installs and the shared Control Plane: a local-first routing default, a provider-neutral local search boundary, and a managed local runtime lifecycle.

## What changed

- Added the shared Control Plane foundation: typed effective configuration, profiles, policy, and `status`/`doctor` diagnostics over the same status object.
- Added five routing modes (`local_only`, `local_first`, `hybrid`, `hosted_only`, `offline_fetch_only`) with `local_first` as the default and `hybrid` retained.
- Added the provider-neutral local search boundary; the current registry binds the neutral contract to the SearXNG adapter.
- Added the Windows provisioning patch and provisioning helper. The patch is an external artifact and is verified at provision time before it is applied.
- Added the Control Plane managed local runtime lifecycle through `ultrasearch-mcp runtime`: provision, start, stop, restart, status, repair, and cleanup for a runtime bound to loopback `127.0.0.1:18099`.
- Repaired the hermeticity test so the suite is insensitive to ambient credential variables.
- Added aggressive runtime, route, and platform test matrices.
- Hardened the release path: the release workflow is manual-dispatch only, and release claims are guarded against implemented behavior.

## Platform scope

The MCPB manifest lists `darwin`, `win32`, and `linux` compatibility for the MCP server itself, while the managed local runtime is Windows-first and refuses `unsupported_platform` on other platforms. The two scopes must not be conflated: installing the MCPB on macOS or Linux provides the cross-platform MCP server, not the managed local runtime.

## Release boundary

This document publishes nothing. No npm package, MCP Registry entry, container image, tag, or GitHub Release is created by it; publication is an Owner action under `docs/release-policy.md`.

## Validated surfaces

- Release metadata identity across `package.json`, `server.json`, and `mcpb/manifest.json`.
- The typed test suite, including the release-metadata identity guard, the release-claims guards, and the runtime, route, and platform matrices.
- Static checks: TypeScript typecheck and Biome lint.
- Hermeticity: the suite is run with the recognized credential variables cleared and again set to canaries.

## Known notes

- The MCPB is not signed yet.
- The managed local runtime verifies and patches a caller-staged root only; automated acquisition, interpreter creation, and package installation remain outside product code, so the one-click runtime remains future work.
- HTTP transport remains an advanced/self-hosted path and should be bound locally or protected at the network layer.
