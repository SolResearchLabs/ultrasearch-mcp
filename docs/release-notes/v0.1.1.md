# UltraSearch MCP v0.1.1

Reliability release candidate for Claude Desktop MCPB installs.

## What changed

- Fixed modern Claude Desktop startup by replaying the `server/discover` request into the MCP v2 server while suppressing duplicate discovery output.
- Fixed MCPB dependency layout by staging production dependencies with hoisted `node_modules`.
- Added bounded MCP tool execution and DNS lookup deadlines so search/fetch failures return before host bridge timeouts.
- Moved heavy tool execution imports behind lazy handlers so `tools/list` remains a lightweight startup path.
- Added smoke coverage for modern discovery, same-process `tools/list`, and hanging-search timeout behavior.

## Release boundary

- Users bring their own provider keys.
- No repository secrets are required.
- Claude Desktop MCPB, npm, MCP Registry metadata, and Docker artifacts are validated by the release workflow.
- HTTP transport remains an advanced/self-hosted path and should be bound locally or protected at the network layer.

## Known notes

- The MCPB is not signed yet.
- This is the clean release path after the existing `v0.1.0` draft/tag, which remains on the earlier release candidate commit.
