# UltraSearch MCP v0.1.0

Initial public release of UltraSearch MCP.

## Highlights

- MCP tools for web search, search and fetch, URL fetch, site crawl, summaries, domain stats, and cache clearing.
- Local-first SearXNG support.
- Optional hosted fallback providers: TinyFish, Exa, Parallel, and Brave.
- Provider provenance in responses so users can see the research route.
- Budget guardrails and hosted-provider controls.
- Runtime config through `ULTRASEARCH_*` env vars and local JSON config.
- One-click style install path for Claude Desktop through MCPB.
- VS Code and Copilot style MCP config with secret input prompts.
- Docker image support for local and self-hosted use.

## User key model

Users bring their own keys. Keys live in their MCP host, OS keychain, Docker secret store, shell environment, or local config file. The public repo does not collect or store user keys.
