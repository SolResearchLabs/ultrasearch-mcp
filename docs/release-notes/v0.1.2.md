# UltraSearch MCP v0.1.2

Reliability release candidate for Claude Desktop MCPB installs and hosted fallback diagnostics.

## What changed

- Added clear hosted-fallback diagnostics when SearXNG is unavailable and hosted providers fail.
- Invalid TinyFish credentials now surface as a provider authorization failure instead of a vague fetch failure.
- Keeps the MCP v2 stdio serving path, modern discovery replay, hoisted MCPB dependency layout, lazy tool-listing, and bounded tool-call deadlines from the hardened candidate line.
- Preserves the package-user key model: users bring their own provider credentials through the MCP host UI or local config.

## Validated surfaces

- Claude Desktop MCPB startup and tool listing.
- npm tarball dry-run.
- MCP Registry server metadata.
- Docker build and MCP label.
- Timeout behavior for hanging local SearXNG endpoints.

## Known notes

- The MCPB is not signed yet.
- HTTP transport remains an advanced/self-hosted path and should be bound locally or protected at the network layer.
